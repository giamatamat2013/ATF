Learn ATF, one program at a time לומדים את ATF, תוכנית אחת בכל פעם

36 short lessons, from the first program to windows and tests. Every output on this page is what the program really printed when the page was built. 36 שיעורים קצרים, מהתוכנית הראשונה ועד חלונות ובדיקות. כל פלט בדף הוא מה שהתוכנית באמת הדפיסה כשנבנה הדף.

Check בדיקה
atf check hello.atf
Run הרצה
atf run hello.atf
Build an .exe בנייה לקובץ exe
atf build hello.atf -o hello.exe

1 Getting started היכרות

01

Your first program התוכנית הראשונה שלכם

Every program starts in fn main(). println prints a line, and print prints without starting a new line.

Text in quotes can hold a value: {expression} is computed and its value is put into the text. This is called interpolation.

Save the code in a file that ends in .atf, then run it with atf run. The compiler checks the program first, then runs it.

כל תוכנית מתחילה ב-fn main(). println מדפיס שורה, ו-print מדפיס בלי לעבור לשורה חדשה.

טקסט במירכאות יכול להכיל ערך: {ביטוי} מחושב, והערך שלו נכנס לטקסט. זה נקרא אינטרפולציה.

שומרים את הקוד בקובץ שמסתיים ב-.atf ומריצים אותו עם atf run. הקומפיילר בודק את התוכנית קודם, ואז מריץ אותה.

atf run 01_hello.atf

02

Comments and line breaks הערות ושבירת שורות

// starts a comment that runs to the end of the line. A statement can continue on the next line when the line ends with an operator, or when the next line starts with a dot. Semicolons are optional.

// פותח הערה שנמשכת עד סוף השורה. פקודה יכולה להמשיך לשורה הבאה כששורה נגמרת באופרטור, או כששורה הבאה מתחילה בנקודה. נקודה-פסיק היא אופציונלית.

atf run 02_comments.atf

2 Values and text ערכים וטקסט

03

Variables: let, var and const משתנים: let, var ו-const

let creates a name that cannot be given a new value, and var creates one that can. const is a global constant. A second let with the same name hides the first one. a, b = b, a swaps two values in one line.

let יוצר שם שאי אפשר לתת לו ערך חדש, ו-var יוצר שם שאפשר. const הוא קבוע גלובלי. let שני עם אותו שם מסתיר את הראשון. השורה a, b = b, a מחליפה בין שני ערכים בשורה אחת.

atf run 03_variables.atf

04

Basic types and conversions טיפוסים בסיסיים והמרות

int is a 64-bit whole number, float a decimal number, bool true or false, str a text and byte a single byte such as 'A'. Conversions are written out: float(n), int(x), str(n) and to_int() on text.

The length of a text counts bytes, not letters. The letter é takes two bytes, so "héllo".len() is 6.

int הוא מספר שלם של 64 סיביות, float מספר עשרוני, bool אמת או שקר, str טקסט, ו-byte בית אחד כמו 'A'. ההמרות כתובות במפורש: float(n), int(x), str(n), ו-to_int() על טקסט.

אורך טקסט נמדד בבתים ולא באותיות. האות é תופסת שני בתים, ולכן "héllo".len() הוא 6.

atf run 04_types.atf

05

Operators אופרטורים

Integer / rounds toward zero, and % takes the sign of its left side. ** is the power operator, and it binds tighter than the minus sign in front of a number. Integers and floats mix in arithmetic, but a float never turns into an integer by itself. ?? gives a default when a value is nil.

חילוק של מספרים שלמים / מעגל לכיוון אפס, ו-% לוקח את הסימן של האגף השמאלי. ** היא חזקה, וקושרת חזק יותר מהמינוס שלפני מספר. מספרים שלמים ועשרוניים מתערבבים בחשבון, אבל עשרוני לעולם לא הופך לשלם מעצמו. ?? נותן ערך ברירת מחדל כשהערך הוא nil.

atf run 05_operators.atf

06

Strings and formatting מחרוזות ועיצוב

Text has methods such as trim, upper, split and repeat, and slices such as word[1..4]. Inside the braces of a text you can add a format: :.2f for two decimals, :5 for a width, :<5 and :>5 to align, and :X or :08b for hexadecimal and binary.

Three quotes make a text over several lines. A raw text, written r"...", ignores backslashes.

לטקסט יש מתודות כמו trim, upper, split ו-repeat, וחתיכות כמו word[1..4]. בתוך הסוגריים המסולסלים של טקסט אפשר להוסיף עיצוב: :.2f לשתי ספרות אחרי הנקודה, :5 לרוחב, :<5 ו-:>5 ליישור, ו-:X או :08b להקסדצימלי ולבינארי.

שלוש מירכאות יוצרות טקסט בכמה שורות. טקסט גולמי, שנכתב r"...", מתעלם מהלוכסנים האחוריים.

atf run 06_strings.atf

3 Control flow בקרת זרימה

07

if and else if ו-else

A condition must be a bool: a number is not true or false. if can also be an expression that gives a value, so it needs an else.

תנאי חייב להיות bool: מספר אינו אמת או שקר. if יכול להיות גם ביטוי שמחזיר ערך, ולכן הוא צריך else.

atf run 07_if.atf

08

while and loop while ו-loop

while repeats as long as its condition holds. loop repeats until a break stops it. continue skips to the next round.

while חוזר כל עוד התנאי מתקיים. loop חוזר עד ש-break עוצר אותו. continue מדלג לסיבוב הבא.

atf run 08_loops.atf

09

for and ranges for וטווחים

0..3 gives 0, 1 and 2, and 0..=3 includes the last number. step sets the jump, and the jump can be negative. for i, x in items gives the index and the value. A label such as outer: lets break outer leave a loop that is nested inside another one.

0..3 נותן 0, 1 ו-2, ו-0..=3 כולל גם את המספר האחרון. step קובע את הקפיצה, והיא יכולה להיות שלילית. for i, x in items נותן את האינדקס ואת הערך. תווית כמו outer: מאפשרת ל-break outer לצאת מלולאה שנמצאת בתוך לולאה אחרת.

atf run 09_for.atf

4 Functions פונקציות

10

Functions פונקציות

Parameters can have default values, and a call can name its arguments. A function with a return type must return a value on every path. The short form => expression returns one expression.

לפרמטרים אפשר לתת ערך ברירת מחדל, ובקריאה אפשר לציין את שמות הארגומנטים. פונקציה עם טיפוס החזרה חייבת להחזיר ערך בכל מסלול. הצורה הקצרה => ביטוי מחזירה ביטוי אחד.

atf run 10_functions.atf

11

Tuples: several results טאפלים: כמה תוצאות

A function can return several values as a tuple, and let (lo, hi) = ... takes them apart. Write _ for a value you do not need. The parts of a tuple are read with .0, .1 and so on.

פונקציה יכולה להחזיר כמה ערכים כטאפל, ו-let (lo, hi) = ... מפרק אותם. כותבים _ לערך שלא צריך. החלקים של טאפל נקראים עם .0, .1 וכן הלאה.

atf run 11_tuples.atf

12

Closures and functions as values סגורים: פונקציות כערכים

|x| x * 2 is a closure, a small function without a name. It can read and change the variables around it. A function can take another function as an argument, and arrays have map, filter and reduce.

|x| x * 2 הוא סגור: פונקציה קטנה בלי שם. הוא יכול לקרוא ולשנות את המשתנים שסביבו. פונקציה יכולה לקבל פונקציה אחרת כארגומנט, ולמערכים יש map, filter ו-reduce.

atf run 12_closures.atf

5 Collections אוספים

13

Arrays מערכים

[int] is an array of whole numbers. push adds at the end, sort sorts the array in place, and nums[1..3] takes a slice. An empty array needs a type, as in var empty: [str] = [].

[int] הוא מערך של מספרים שלמים. push מוסיף בסוף, sort ממיין את המערך במקום, ו-nums[1..3] לוקח חתיכה ממנו. מערך ריק צריך טיפוס, כמו ב-var empty: [str] = [].

atf run 13_arrays.atf

14

List comprehensions הבנות רשימה

A comprehension builds an array from a loop in one expression. An if at the end keeps only some of the items, and comprehensions can be nested to build a grid.

הבנת רשימה בונה מערך מתוך לולאה בביטוי אחד. if בסוף משאיר רק חלק מהפריטים, ואפשר לקנן הבנות כדי לבנות טבלה.

atf run 14_comprehensions.atf

15

Maps מפות

A map such as {str: int} stores values under keys, and it keeps the keys in the order they were added. get(key, default) returns the default when the key is missing, in checks for a key, and for k, v in map visits every pair.

מפה כמו {str: int} שומרת ערכים לפי מפתחות, ושומרת את המפתחות לפי סדר ההוספה. get(key, default) מחזיר את ברירת המחדל כשהמפתח חסר, in בודק אם מפתח קיים, ו-for k, v in map עובר על כל הזוגות.

atf run 15_maps.atf

16

Sets קבוצות

A set keeps each value only once. Create one with set_new::<int>(), check membership with in or has, and go over the items with items().

קבוצה שומרת כל ערך רק פעם אחת. יוצרים אותה עם set_new::<int>(), בודקים אם ערך נמצא בה עם in או has, ועוברים על הפריטים עם items().

atf run 16_sets.atf

6 Your own types טיפוסים משלכם

17

Structs and methods מבנים ומתודות

A struct groups named fields. impl adds methods: a method takes self, and a function without self is called on the type, as in Point.new(9). A method named to_str is used by println and by text interpolation.

Structs are references: var moved = a gives a second name for the same point, so changing moved also changes a.

מבנה מאגד שדות בעלי שם. impl מוסיף מתודות: מתודה מקבלת self, ופונקציה בלי self נקראת על הטיפוס עצמו, כמו Point.new(9). מתודה בשם to_str נקראת על ידי println ועל ידי הכנסת ערך לטקסט.

מבנים הם הפניות: var moved = a נותן שם שני לאותה נקודה, ולכן שינוי של moved משנה גם את a.

atf run 17_structs.atf

18

Operators on your own types אופרטורים על הטיפוסים שלכם

Methods named op_add, op_mul, eq and cmp make +, *, == and < work on your type. cmp returns a negative number, zero or a positive number, and sort uses it to order the items.

מתודות בשם op_add, op_mul, eq ו-cmp גורמות ל-+, *, == ו-< לעבוד על הטיפוס שלכם. cmp מחזיר מספר שלילי, אפס או חיובי, ו-sort משתמש בו כדי לסדר את הפריטים.

atf run 18_operators.atf

19

Enums and match Enum ו-match

An enum lists the possible cases, and a case can carry data. match runs the arm that fits the value, and it must cover every case or end with _. A numbered case gives an integer through int(...).

Enum מונה את המקרים האפשריים, ולמקרה יכול להיות מידע צמוד. match מפעיל את הזרוע שמתאימה לערך, וחייב לכסות את כל המקרים, או להסתיים ב-_. למקרה עם מספר נותנים ערך שלם בעזרת int(...).

atf run 19_enums.atf

20

Patterns תבניות

A pattern can match a value, a range such as 4..=9, or several values separated by |. A guard with if adds a condition. Structs, tuples and arrays can be matched too: [first, ..rest] takes the first item and the rest of the array.

תבנית יכולה להתאים לערך, לטווח כמו 4..=9, או לכמה ערכים שמופרדים ב-|. שמירה עם if מוסיפה תנאי. אפשר להתאים גם מבנים, טאפלים ומערכים: [first, ..rest] לוקח את הפריט הראשון ואת שאר המערך.

atf run 20_patterns.atf

7 Generics, interfaces and iterators גנריות, ממשקים ואיטרטורים

21

Interfaces ממשקים

An interface lists methods. Any type that has those methods fits, without declaring that it does, so one [Shape] array can hold circles and squares. A method in an interface can also have a default body that types use when they do not write their own.

ממשק מפרט מתודות. כל טיפוס שיש לו את המתודות האלה מתאים, בלי הצהרה מיוחדת, ולכן מערך [Shape] אחד יכול להחזיק עיגולים וריבועים. למתודה בממשק יכול להיות גם גוף ברירת מחדל, שבו הטיפוסים משתמשים כשאינם כותבים מתודה משלהם.

atf run 21_interfaces.atf

22

Generics גנריות

<T> after the name of a function or a struct makes it work for any type. The compiler checks each use with the real type, so you do not write bounds.

<T> אחרי שם של פונקציה או מבנה הופך אותם לעובדים על כל טיפוס. הקומפיילר בודק כל שימוש עם הטיפוס האמיתי, ולכן לא כותבים הגבלות על הטיפוס.

atf run 22_generics.atf

23

Your own iterators איטרטורים משלכם

Any type with a method next(self) -> T? can be used in a for loop. The loop stops when next returns nil.

כל טיפוס שיש לו מתודה next(self) -> T? יכול לשמש בלולאת for. הלולאה נעצרת כש-next מחזיר nil.

atf run 23_iterator.atf

8 Optionals and errors אופציונלים ושגיאות

24

Optionals: values that may be nil אופציונלים: ערכים שעשויים להיות nil

int? is an integer or nil. It cannot be used as a plain integer until you open it: ! opens it and panics on nil, ?? gives a default, and if let runs only when there is a value.

int? הוא מספר שלם או nil. אי אפשר להשתמש בו כמספר רגיל לפני שפותחים אותו: ! פותח ונופל על nil, ?? נותן ברירת מחדל, ו-if let רץ רק כשיש ערך.

atf run 24_optionals.atf

25

Result and the ? operator Result ואופרטור ה-?

Result<T, E> is either Result.Ok(value) or Result.Err(error). A ? after a call returns the error from the current function when there is one, and otherwise gives the value.

Result<T, E> הוא Result.Ok(ערך) או Result.Err(שגיאה). ? אחרי קריאה מחזיר את השגיאה מהפונקציה הנוכחית כשיש שגיאה, ואחרת נותן את הערך.

atf run 25_result.atf

26

panic, catch_panic, try and defer panic, catch_panic, try ו-defer

panic stops the program with a message and a traceback. catch_panic runs a function and returns the message instead of stopping, and try ... catch does the same for a block. defer runs its line when the enclosing block ends, and several defers run in reverse order.

panic עוצר את התוכנית עם הודעה ו-traceback. catch_panic מריץ פונקציה ומחזיר את ההודעה במקום לעצור, ו-try ... catch עושה את אותו דבר לבלוק. defer מריץ את השורה שלו כשהבלוק שמכיל אותו מסתיים, וכמה defer-ים רצים בסדר הפוך.

atf run 26_errors.atf

9 Programs and the outside world תוכניות והעולם החיצון

27

Files קבצים

read_file returns the text of a file, or nil when the file cannot be opened. write_file returns true on success, and path_join joins a folder and a file name with the right separator. This program writes a file to the temporary folder, reads it back and deletes it.

read_file מחזיר את הטקסט של קובץ, או nil כשאי אפשר לפתוח אותו. write_file מחזיר true בהצלחה, ו-path_join מחבר תיקייה ושם קובץ עם המפריד הנכון. התוכנית הזו כותבת קובץ לתיקייה הזמנית, קוראת אותו ומוחקת אותו.

atf run 27_files.atf

28

Command-line arguments ארגומנטים משורת הפקודה

fn main(args: [str]) receives what is written after the program name. The number that main returns becomes the exit code. Pass arguments after the file name, as in atf run 28_args.atf hello world. The output below was made without arguments.

fn main(args: [str]) מקבלת את מה שכתוב אחרי שם התוכנית. המספר ש-main מחזיר הופך לקוד היציאה. מעבירים ארגומנטים אחרי שם הקובץ, כמו ב-atf run 28_args.atf hello world. הפלט שלמטה נוצר בלי ארגומנטים.

atf run 28_args.atf

29

Modules: your own files מודולים: קבצים משלכם

import "shapes" loads shapes.atf from the same folder, and everything in it becomes available: functions, types and constants. All files share one global namespace, so every global name must be unique. The standard library needs no import line: a name such as json_parse loads its module by itself.

import "shapes" טוען את shapes.atf מאותה תיקייה, וכל מה שבו נעשה זמין: פונקציות, טיפוסים וקבועים. כל הקבצים חולקים מרחב שמות גלובלי אחד, ולכן כל שם גלובלי חייב להיות ייחודי. לספרייה הסטנדרטית לא צריך שורת import: שם כמו json_parse טוען את המודול שלו בעצמו.

atf run 29_modules.atf

30

Standard library: JSON ספרייה סטנדרטית: JSON

std/json reads and writes JSON. json_parse returns a Result, so a broken document is an error that you can handle. json_stringify writes the text, and its second argument sets the indentation.

std/json קורא וכותב JSON. json_parse מחזיר Result, ולכן מסמך שבור הוא שגיאה שאפשר לטפל בה. json_stringify כותב את הטקסט, והארגומנט השני שלו קובע את ההזחה.

atf run 30_json.atf

31

Tests with std/test בדיקות עם std/test

test runs a named group of checks. expect_eq and expect record a failure and let the rest run, and expect_panics passes only when the code panics. atf test runs every test file in a folder.

test מריץ קבוצה של בדיקות בעלת שם. expect_eq ו-expect רושמים כישלון ומאפשרים לשאר הבדיקות לרוץ, ו-expect_panics עובר רק כשהקוד נופל. atf test מריץ כל קובץ בדיקה בתיקייה.

35

Traps to avoid מלכודות לשים לב אליהן

Assigning an array, a map or a struct gives a second name for the same value, so use copy when you need an independent copy. Integers wrap around without a warning when they go past their largest value.

השמה של מערך, מפה או מבנה נותנת שם שני לאותו ערך, ולכן משתמשים ב-copy כשצריך עותק עצמאי. מספר שלם מתגלגל בלי אזהרה כשהוא חורג מהערך הגדול ביותר שלו.

atf run 35_traps.atf

36

Building text fast בניית טקסט מהירה

Joining pieces with + inside a loop copies the text again and again. A str_builder collects the pieces, and finish returns the result once. array_make::<int>(n) makes an array of a set size in one step.

חיבור חלקי טקסט עם + בתוך לולאה מעתיק את הטקסט שוב ושוב. str_builder אוסף את החלקים, ו-finish מחזיר את התוצאה פעם אחת. array_make::<int>(n) יוצר מערך בגודל נתון בצעד אחד.
